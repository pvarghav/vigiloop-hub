---
description: Show or change which of this computer's Claude Code sessions show up in Vigiloop (global or strict)
argument-hint: "[global|strict]"
---

Run with the Bash tool: "${CLAUDE_PLUGIN_ROOT}/runtime/vigiloop" mode $ARGUMENTS

Global (the default): every Claude Code session on this computer shows up in Vigiloop. Strict: only sessions the user ran /vigiloop:enable in. Tell the user the result in one or two sentences.
